# Frame Shelf · AE 2025 组合导出（开发测试版）

记录主合成各图层的独显、可见开关与当前帧，将组合分配给可编辑的名称槽位，最后统一导出静帧。命名预设与 AE 输出模块模板独立：你决定名称，也在 AE 中自行决定输出格式、位深、透明通道、压缩与色彩设置。

本版本是 CEP 扩展，适用 Windows / AE 2025（25.x）。不依赖 Media Encoder；渲染期间 AE 会被占用。浏览器页面仅演示交互，不能操作 AE。

## 安装：直接复制文件夹

1. 解压 `FrameShelf-0.8.3-Portable.zip`，找到 `com.frameshelf.ae` 文件夹。
2. 关闭 AE，把这个文件夹整体复制到以下目录（目录不存在时可自行创建）：

   ```text
   %APPDATA%\Adobe\CEP\extensions\
   ```

   在资源管理器地址栏粘贴上述路径即可。当前电脑对应：

   ```text
   C:\Users\adminss\AppData\Roaming\Adobe\CEP\extensions\
   ```

   安装后必须能找到 `extensions\com.frameshelf.ae\CSXS\manifest.xml`，不要多套一层文件夹。此版本是 CEP 面板，不能放进 AE 的 `Support Files\Plug-ins` 或 `Scripts\ScriptUI Panels` 目录。
3. 更新已有版本时，先将旧 `com.frameshelf.ae` 文件夹备份到 extensions 目录外，再复制新的文件夹；避免安装两份相同扩展。无需运行 cmd 或 PowerShell。
4. 重启 AE 2025，在「窗口 → 扩展」打开 `Frame Shelf · 组合导出`。
5. AE「首选项 → 脚本和表达式」需要启用「允许脚本写入文件和访问网络」。插件本身不需要网络。

### 未签名测试版的首次加载

复制安装不会自动更改系统设置。本包尚未签名，需要当前用户已启用 CEP 12 开发扩展加载。如果此前成功运行过旧安装程序并能打开面板，此设置已完成，后续更新只需复制文件夹。

如果首次安装后扩展菜单未出现，可手动在注册表编辑器检查：

- 位置：`HKEY_CURRENT_USER\Software\Adobe\CSXS.12`
- 名称：`PlayerDebugMode`
- 类型：字符串值（REG_SZ）
- 数据：`1`

该设置允许当前用户加载所有未签名 CEP 12 开发扩展，不只影响 Frame Shelf。复制式安装包没有包含自动修改注册表的脚本。要完全免除此首次开发设置，需要后续制作正式签名发行包。

组合及命名预设保存在 `%APPDATA%\FrameShelf`，替换扩展文件夹不会删除这些数据。手动复制更新不会自动备份旧扩展，请按上述步骤自行保留旧版。

## 使用

1. 工程先保存一次，激活需要导出的主合成时间线。
2. 独显 compA + compB，移动到所需帧，点击「添加组合」。切换 compC、compA 等状态后继续添加。预览直接提取当前帧，PNG 8/16 位、长边不超过 960 像素，不进入渲染队列，也不保存工程。等待预览完成后可继续记录；复杂画面仍需要 AE 计算。预览失败时组合记录保留，可点击「预览」重试。
3. 打开「命名与导出」独立窗口，在右侧输出卡片直接编辑名称，例如 `吸尘器_Prouduct`、`吸尘器_Final`、`吸尘器_BG`。也可用 `{产品名}` 变量并保存命名预设。
4. 打开拖拽分配工作台，将组合拖到名称卡片，或先点击组合再点击目标卡片。同一组合可分配到多个名称。取消勾选的槽位不输出。
5. 在 AE「编辑 → 模板 → 输出模块」保存自己的输出模块模板。也可点击导出窗口底部「管理模板」打开 AE 原生模板管理，关闭后列表自动刷新；在底部下拉框选择模板。首版支持 RGB/RGBA 的 TIFF、PNG、JPEG。TIFF 16 位须由你在 AE 模板中设置，选择格式并不自动提高工程精度。
6. 模板请关闭缩放和裁切。插件固定单帧、完整合成尺寸，禁用代理和导引层，保留当前效果、运动模糊与帧混合状态；输出模块的其他设置沿用你的模板。插件不执行模板的渲染后导入动作。
7. 选择本地 NTFS 输出文件夹，点击「检查并导出」，核对清单后开始。

## 边界与恢复

- 组合记录不是工程快照。文字、效果、素材、嵌套合成在导出时读取最新内容。预览可能落后于当前工程，必要时刷新。
- 图层增删/替换、合成尺寸/像素比例/帧率变化后须重新添加组合。图层重排和改名按稳定 ID 识别。另存为会建立独立组合库。
- 原队列的待渲染任务会临时取消勾选，任务结束后恢复；图层开关也恢复。临时渲染操作可能使工程显示已修改。
- 面板的「当前帧后停止」只阻止后续任务。要中止正在渲染的一帧，使用 AE 渲染队列的停止按钮。
- 意外中断后面板提供恢复记录；先检查工程与队列，再恢复或选择已手动检查。不要在渲染期间修改组合、工程或队列。
- 原图先写入目标文件夹下独立的 `.frameshelf-*` 临时目录，校验图片结构和尺寸/位深/通道元数据后提交。校验不是完整像素解码。采用同卷硬链接保证不覆盖已有文件，暂不支持不能创建硬链接的 FAT/exFAT 或部分网络盘。失败的临时目录保留用于排查。
- 超大图渲染受内存、素材、效果和第三方插件限制；简单合成测试通过不等于所有 15K 工程都保证成功。

## 开发验证

`npm test` 验证命名、持久化、文件防覆盖、图片元数据及任务恢复逻辑；`npm run check` 检查语法和入口资源。`npm run preview` 在 `http://127.0.0.1:4173` 展示明确标注的演示页面。

真实 AE 的测试结果见工作目录 `docs/TEST-RESULTS.md`。本开发版仍需实际工作工程验收，不作为正式稳定版承诺。

## 0.2.0 更新（2026-10-09）

- 修正渲染事务中跨越 render() 的撤销组用法；保留显式状态恢复。需在 AE 中复测截图所示警告是否消失，尚未宣称实际导出故障全部解决。
- 添加组合按钮始终显示文字并高亮。
- 点击「打开拖拽分配工作台」，左侧为组合、右侧为命名卡片；拖入分配，或先点组合再点目标。原下拉分配已移除。此工作台是面板内独立视图，可以使用 AE 的面板浮动方式扩大窗口。
- 「另存预设」保存新预设；「更新预设」保存当前预设的修改。预设包含名称规则和自定义字段，不保存具体工程的组合绑定。
- 「自定义名称字段」可增加命名A、命名B等字段。输出名称可写 `{命名A}_{命名B}_$DD$hh$mm`；也可点选名称输入框后，点击片段按钮追加。
- 日期通配符：`$YYYY` 四位年、`$YY` 两位年、`$MM` 月、`$DD` 日、`$hh` 小时、`$mm` 分钟、`$ss` 秒。采用电脑本地时间，整个批次统一取导出清单生成时的时间。未知通配符会报错，不会原样输出。图片二中的相机/渲染引擎等其他软件专有变量不在本版支持范围。
- 输出前检查失败也进入导出记录，并显示可取得的 AE 脚本行号。

## 0.3.0：独立命名导出窗口与预览修复

主面板只负责添加组合、查看与刷新预览。点击「命名与导出 ↗」打开独立、可调整大小的 CEP 浮动窗口。命名预设、自定义字段、通配符、名称编辑、组合拖拽与输出设置全部集中在这个窗口。主面板添加/删除组合和生成预览后，导出窗口自动同步；关闭导出窗口不会关闭主面板。

替换扩展文件夹后需要重启 AE：新增窗口在 CEP 启动时注册，仅重新打开旧面板可能无法发现它。

预览修复包括：使用准确的单帧工作区渲染并恢复原工作区；修复 ExtendScript 对连续三元条件表达式的不同求值行为导致的格式/位深误识别。模板仍然使用用户自己的设置。

AE 的部分 TIFF 输出把第四通道的 ExtraSamples 标记写成 0（未指定）。当模板明确为 RGB+Alpha 且提供 Straight/Premultiplied 类型时，本版仅将这个标签修正为对应标准 Alpha 标记，不改变像素、压缩或位深；不符合该结构的文件仍报错。导出记录保存是否进行了标记修正。

本机已有五个 6100×10000 组合的低分辨率 PNG 预览已实机生成成功。不同帧率的单帧小图测试通过。15K TIFF 16 位完整输出仍需独立验收，不能用预览成功代替。

## 0.4.0 界面调整

取消插件设置页和预览设置。底部直接选择 AE 输出模块模板；「管理模板」进入 AE 原生模板管理，模板由 AE 保存。右侧名称卡片包含可编辑名称、导出勾选、删除、组合预览及最终文件名；名称片段按钮位于卡片上方。左侧保留命名预设、产品名及自定义字段。

原生模板管理窗口需自行选择要修改的模板；插件不保证原生窗口自动选中底部所选模板。修改完成后关闭原生窗口，列表自动刷新，也可手动刷新。

## 0.4.1 组合更新与卡槽管理

0.5.0 起组合库按工程路径＋源合成 ID 隔离。切换合成会恢复各自的组合、卡槽、产品名、自定义字段及导出记录。再次输出读取各源合成最新内容，并恢复对应记录的图层开关与帧。

要修改已记录的独显组合或帧，在 AE 激活同一个源合成并调整后，点击组合库卡片的「更新组合」。保留组合名称、ID 与卡槽分配，重新生成预览；在其他源合成点击会拒绝更新。图层增删、尺寸等变更也可重新更新记录。

输出卡片支持直接改名、拖入其他组合替换分配、「清除分配」和「删除卡槽」。删除卡槽不删除组合库记录，也不改变已保存预设；需要同步到预设时点击「更新预设」。

## 0.5.0 按合成隔离

两个窗口空闲时自动跟随 AE 当前合成，顶部显示当前合成名称。正在输入或渲染时暂缓切换；输入结束后恢复跟随。新合成使用空组合库和默认命名预设，返回旧合成恢复其数据。合成改名不改变归属，同名合成以 ID 区分。导出检查拒绝跨合成记录。

首次打开某个合成时，自动从旧工程级数据提取该合成记录和已关联卡槽。未分配卡槽复制到有旧记录的各合成；可明确关联的历史记录随卡槽迁移。旧工程级文件完整保留，无法确定归属的历史仍在原文件。后续不重复导入，删除的卡槽不会因迁移重新出现。命名预设和 AE 输出模板设置仍共享，可在各合成套用同一预设。

## 0.6.0 界面精修与联动字段

独立导出窗口采用 48px 导航＋32px 当前合成栏；移除重复的大标题、说明行，成功提示 4.5 秒后消失。预设、组合、输出卡片三栏独立滚动；底部固定输出模板、目录和主导出按钮。日期片段菜单默认收起，需要时展开。

「添加联动字段」同时填写字段名称和内容，选择全部输出名称或单个名称。默认应用当前编辑的卡片，尚未选择卡片时默认全部；保存后把 `{字段名}` 加到对应名称末尾。修改左侧字段或产品名，右侧最终文件名立即更新。删除字段同时移除名称中的对应片段。预设仍保存字段和名称规则。

原生模板按钮准确标为「管理模板」。AE 25.2 的 OutputModule 运行时方法包含 applyTemplate/getSettings/setSettings/saveAsTemplate 等，但没有打开指定模板编辑窗口的方法；目前只能进入原生模板管理器后自行选择模板。此版本没有实现一键定位并打开指定模板编辑窗口，也不会修改系统偏好来强行改变默认模板。

## 0.7.0 顺序命名字段

左侧命名字段支持拖动、上移/下移和删除。固定名称：一处修改所有槽位同步；通配符字段：输入 $YYYY、$YY、$MM、$DD、$hh、$mm、$ss 或组合；自定义名字：在每张卡片独立填写，可以添加多个。字段标题可编辑。字段分隔符最多 10 个字符，默认下划线，可使用短横线、空格或留空直接拼接；Windows 文件名非法字符会在导出检查时拦截。

预设保存字段类型、顺序、固定值、各槽位独立名称和分隔符。旧命名规则优先按下划线分段迁移；复杂且不同结构的规则保留为兼容字段，继续解析原变量/通配符。迁移保留 legacyNaming 数据，现有卡槽分配不变。新字段排序功能不改变 AE 渲染逻辑。

## 0.7.1

组合预览卡片增加删除组合按钮；清空关联卡槽的分配，保留名称及独立值，不删除 AE 合成或已导出文件。删除状态跨窗口同步，旧窗口写入不会复活已删除记录。

## 0.8.0 更新（2026-10-09）

- 添加组合和刷新预览改用 AE 当前帧 PNG 提取，不再借助渲染队列，不依赖输出模块模板。
- AE 可能延迟写出 PNG：插件异步等待结构完整且文件大小/修改时间稳定后再保存预览，最多等待 60 秒。失败保留组合，不自动转回队列渲染。
- 提取前后恢复图层独显、可见开关与合成预览分辨率；最终高质量导出保持原有 AE 输出模块流程。
- 原版本 Git 基线：`9071c50`，标签 `frameshelf-0.7.1-baseline`；开发分支 `codex/direct-preview`。
- 使用 AE 的 `saveFrameToPng` 接口生成画面预览，并非操作系统屏幕截图。该接口没有稳定的公开脚本契约，当前只验证本机 AE 2025，其他版本和复杂效果仍需验收。

## 0.8.1 修复

修正关闭可见性的图层触发 solo 写入错误的问题，应用与恢复图层状态共用安全顺序。AE 返回空输出时保留恢复记录，不再直接读取空值的 path。

## 0.8.2 修复

直接帧预览接受 8 位和 16 位 PNG，不再沿用旧渲染队列预览只接受 8 位的限制。错误信息列出实际格式、位深、尺寸和字节数。

## 0.8.3 命名交互

输出卡片顶部显示最终文件名，删除底部重复预览。字段整行不再设置 HTML draggable，保留序号手柄拖动与上下移动。固定字段和槽位名字在输入法组词完成后同步，避免提交中间拼音。
